# Contributing to the Trucking and logistics jobs list

Help drivers and logistics workers find openings with clear work requirements. Include the employer's posting so readers can check routes, shifts, and qualifications.

## What belongs in this list

Truck driving, delivery, warehouse, dispatch, freight, and logistics operations roles belong here.

## Suggest a job

Include the exact role title, employer's own apply link, location, and any stated license or shift requirement.

[Open the Add a job form](https://github.com/Jobhacki/trucking-logistics-jobs/issues/new?template=add-a-job.yml)

## Report a dead link

Include the driving or logistics role title, employer, link, and whether the posting is missing or filled.

[Open the Report a dead link form](https://github.com/Jobhacki/trucking-logistics-jobs/issues/new?template=report-a-dead-link.yml)

## Ground rules

- Use the issue forms above. The table in the README is generated, so a pull request that edits it will be overwritten on the next refresh.
- Links must go to the employer's own career page or hiring system. Links to job aggregators and links with tracking or session parameters are not added.
- Please do not include personal data about anyone.
- We review suggestions by hand and cannot promise a timeline or that every suggestion is added. The employer's page is always the source of truth for a listing.
